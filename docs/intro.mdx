- 注册账号、登录、浏览、发帖、回复、发送私信、使用 shoutbox 或本站其他功能，均视为已阅读、理解并同意本条款。

- 本条款与本站另行发布的社区规则、版块公告同时适用；如有冲突，以本条款为准，版块内更严格的具体约定在该版块内优先。

## 二、账号注册与账号安全

- 注册须提供真实、有效且可接收邮件的邮箱地址，并通过邮箱验证码或邀请码完成验证。本站仅发送验证码、安全提醒与必要通知类邮件。
- 邮箱地址统一以小写形式保存；一个用户原则上仅可持有一个账号。禁止批量注册、买卖、租借、共享账号或冒用他人身份。
- 用户名、签名、头像不得包含冒充管理团队、误导性、侮辱性、歧视性或违法内容；管理团队有权要求修改。
- 密码以不可逆哈希方式存储。请自行妥善保管密码与登录凭证，因外借、泄露或保管不当造成的损失由用户自行承担；发现异常登录后请尽快修改密码并联系管理员。
- 本站工作人员不会在任何场合向你索要密码或邮件验证码。收到此类索取请直接举报。

## 三、用户行为规范

- 发布违反中华人民共和国法律法规的内容，包括危害国家安全、破坏民族团结、宣扬暴力、色情、赌博、毒品或教唆违法犯罪的内容；
- 人身攻击、歧视、骚扰、威胁、人肉搜索，或未经同意公开他人隐私信息；
- 发布垃圾广告、刷屏、恶意导流、诈骗信息、虚假消息或未经核实的爆料；
- 传播病毒、木马、盗号程序、外挂及其他破坏性程序，或利用漏洞、脚本、自动化工具绕过人机验证、批量抓取、刷量、干扰服务正常运行；

- 恶意举报、规避封禁、协助他人规避管理措施。

## 五、版块权限与社区管理

- 管理团队可按「全体用户」或一个或多个用户组，为分类及单个版块设置访问权限：不可查看、仅阅读、仅阅读与回复、可编辑（不含删除与置顶锁定）、不限制。

- 「不可查看」的版块内容不会出现在版块列表、最新主题、搜索结果、侧栏动态与用户资料的活动记录中。

## 七、隐私与数据处理

本条构成本站的《隐私政策》。

- **收集范围**：注册邮箱、用户名、密码哈希、个人资料与偏好设置（如时区、邮件设置、所属用户组）、发布内容与私信内容、登录时间与必要的网络信息（如 IP 地址、User-Agent）、用于维持登录状态的令牌，以及为保障安全产生的操作日志。
- **使用目的**：账号验证与登录、内容与权限的展示和检索、按用户组执行版块权限、发送必要的验证与通知邮件、安全审计与反滥用、故障排查。不会用于与本社区服务无关的商业画像或自动化决策。
- **人机验证**：本站使用自托管的工作量证明验证拦截自动化请求。验证过程不采集访客行为画像、不写入持久追踪标识、不向其他第三方发起请求。
- **本地存储**：浏览器本地存储仅用于保存登录令牌与界面偏好，不用于跨站追踪。清除浏览器数据或退出登录即可移除令牌。
- **不售卖与不共享**：本站不出售、出租或交易用户个人信息，也不会向无关第三方提供。仅在法律法规要求、司法机关依法调取，或为保护本站与其他用户安全所必需时，在最小范围内披露。
- **邮件服务**：验证码与安全通知由本站自有域名邮箱发送，仅用于完成对应操作，不会附带追踪像素或用于营销。
- **保留期限**：信息在账号存续期间保留。账号注销后，本站将在合理期限内删除或匿名化个人信息；依法需留存的记录，以及已沉淀为社区讨论且脱离个人可识别性的内容，可能继续保留。
- **你的权利**：可查阅、更正个人资料，可申请注销账号或导出本人公开发布的内容。请通过第十条的联系方式提出，本站将在核验身份后处理。
